# C++ Laboratory Works

OC - Arch Linux

Оригінальне завдання використовує специфічні функції Windows API, яких не існує в Linux. Для успішної компіляції їх було замінено на сучасні аналоги зі стандартної бібліотеки C++. Це дозволило повністю зберегти необхідну логіку роботи з кодуваннями та зробити код універсальнішим і незалежним від операційної системи.
