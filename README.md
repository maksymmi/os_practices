# C++ Pracice Works

OC - Arch Linux

!!! Шосте практичне завдання було адаптоване під стандарт POSIX !!!

Примітка щодо операційного середовища -> 
Усі завдання п'ятої, шостої та сьомої практичних робіт були виконані в операційній системі сімейства Linux з використанням компілятора GCC (g++). У зв'язку з цим вихідні коди програм та інструкції з компіляції були адаптовані під стандарти POSIX та специфіку роботи з динамічними бібліотеками форматів .so (Shared Objects). Замість функцій Windows API (LoadLibrary, GetProcAddress, FreeLibrary), для динамічного завантаження було використано стандартні системні виклики <dlfcn.h> (dlopen, dlsym, dlclose), а перевірка переповнення розрядної сітки реалізована через оптимізовані вбудовані функції компілятора GCC (__builtin_overflow).
